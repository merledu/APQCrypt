7 · Wrapper interface (external connections)
How APQCrypt connects to the outside world: the things it uses, and the doors other programs can use to call it.
Two directions:
Things we use (wrapped by adapters): the packet source (Mininet + tshark, or a capture file), the AI model file, and the ML-KEM library. The pipeline talks to an adapter, not to the library directly, so you can switch a connection here without changing pipeline code.
Programs that use us (REST API): another tool can ask "which protection does this conversation need?" or upload a capture, using a documented API with a key. A Python client and command-line tool are included.
External connections
The active connection is used by the next run. Packet source "Capture file" lets you run without Mininet. The simulated ML-KEM is for development only and is never counted as quantum-safe.

Python client and command line (apqcrypt_client.py)


from apqcrypt_client import APQCryptClient
c = APQCryptClient("http://127.0.0.1:5000", key)          # key from data/api_key.txt
print(c.decide(protocol="HTTPS", dest_port=443)["decision"])  # one conversation
job = c.analyze("capture.pcapng")                             # whole capture file
print(c.decisions(job["id"])["decisions"][:3])

# command line
python apqcrypt_client.py health
python apqcrypt_client.py decide --protocol HTTPS --port 443 --resource CONSTRAINED
python apqcrypt_client.py analyze data/traffic.pcapng
