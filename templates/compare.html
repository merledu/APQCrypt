Comparison: Normal vs Adaptive

Compare conventional encryption, all-quantum-safe encryption, and APQCrypt adaptive encryption using the same recorded traffic.

How the comparison works

A. Normal: X25519 key exchange with AES-256-GCM for every flow. This represents conventional encryption and is not quantum-safe.

B. All quantum-safe: Hybrid X25519 + ML-KEM-1024 key exchange for every flow, with a higher expected computational cost.

C. APQCrypt (adaptive): Selects its encryption policy according to traffic sensitivity and system conditions.

Expected outcome: Adaptive encryption should reduce the cost compared with applying quantum-safe key exchange to every flow, while protecting HIGH-sensitivity flows with quantum-safe key exchange.

Run the normal pipeline first so a capture and sensitivity scores are available. The first run of each mode should be treated as a warm-up and excluded from counted measurements.

Measurement note: These benchmarks measure processing cost on this computer, not live network latency. Results should only be compared when the capture and test conditions are equivalent.
