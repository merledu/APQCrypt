Press Measure on a mode to run it for real. Each run is a fresh process on the same capture, so time, CPU and memory are honest. The first run of each mode is a warm-up and is not counted. A bar appears only for a mode you measured. Results from another computer or another capture are kept apart. This measures processing cost on this machine. It is not live network delay.
