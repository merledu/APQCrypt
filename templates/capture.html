Capture and feature extraction

Traffic recorded from the Mininet test network, and the per-packet features extracted from it.

How this stage works

A two-host Mininet topology (h1, s1, h2) generates ICMP, UDP, DNS, HTTP, HTTPS and SSH traffic. tshark records it on the switch interface into traffic.pcapng.

Scapy then reads every packet and extracts addresses, ports, protocol, TTL, TCP flags, window size, packet size, a flow identifier and the first 128 bytes of the payload as hex. Those bytes are used only to read protocol fields that are sent in clear text, such as the TLS server name, the DNS query name and the SSH banner. Nothing is decrypted.
