8 · Configuration interface
Change how APQCrypt behaves without touching code. Changes apply to the next run and are saved with that run.
How it works: pick a preset or edit the values, then press Save. Every value is checked first. The most important safety rule: HIGH must stay quantum-safe unless you tick "Allow unsafe settings" for an experiment, and only tamper-detecting locks are allowed. After saving, press Start (or re-run from the Debug page) and watch the results change.
