Encryption

One key exchange per flow, then every packet of that flow is encrypted with the selected cipher.

How encryption is applied

Key exchange runs once per flow: X25519, or X25519 combined with ML-KEM (hybrid) for sensitive traffic. Key derivation mixes the shared secrets with HKDF. Encryption then protects each packet payload with AES-GCM or ChaCha20-Poly1305.

Self-checks. A sample of packets is decrypted to confirm correctness, and one bit is flipped to confirm tampering is detected.

Prototype limitation. Both ends of each key exchange run inside the same process.
